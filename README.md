# Description

The Address Book is a simple C program that allows users to store and manage contact details. It helps in organizing information like names, phone numbers, and addresses in a structured way.

# Features

* Add new contacts
* View all contacts
* Search for a contact
* Edit contact details
* Delete contacts

# Concepts Used

* Structures (`struct`)
* Functions
* File handling (optional, if you used it)
* Arrays and strings

# Purpose

This project is created to practice basic C programming concepts and understand how real-world applications manage data using structures and functions.
